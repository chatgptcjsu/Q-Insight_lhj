# Q·INSIGHT 공정 품질 관리 화면 시안

## 프로젝트 개요
- **목표**: 초지 3·4·5호기의 검사성적서 데이터를 한 화면에서 확인하고, 호기별 품질 분석 시스템으로 확장합니다.
- **현재 구현**: 전체 현황, 초지345 원본 데이터 표/필터, 입력 이상 후보 검토, 호기별 검사 요약·기록, `통계분석 정리(초지)` 기반 통계표와 월별 상자그림
- **통계표 기능**: 호기별 3·4·5호기 구분, 통계 항목 탭, 평균·σ·CPK 및 월별 값 표시, 월 열 가로 스크롤 지원
- **상자그림 기능**: `초지345` 원본의 숫자 측정값이 있는 모든 품목을 호기·월·항목별로 묶어 상자그림을 표시. 현재 파일에는 호기별 평량 10/14/13개 품목, 파열강도·인장강도도 각 동일 품목군을 포함
- **품명 별칭 예시**: 정확히 등록한 원본 품명만 표준 품명으로 합침. 유사 문자열을 자동 병합하지 않음
- **기술 상태**: 현재는 Hono 기반으로 화면 시안을 띄우는 단계입니다. 앞서 설치한 Java 17·Maven·MariaDB를 이용한 Spring Boot 백엔드 및 DB 저장 기능은 아직 연결하지 않았습니다.

## 화면 경로
- `/` — 초지 3·4·5호기 선택 및 전체 요약
- `/machine/3` — 초지 3호기 현황
- `/machine/4` — 초지 4호기 현황
- `/machine/5` — 초지 5호기 현황
- `/machine/:id?section=weight|burst|tensile` — 호기별 통계분석 항목 선택
- `/inspection` — 초지345 원본 표와 호기·월·품명·판정 필터, 의심값 검토

## 데이터 참고
- 업로드된 `2026 화장지 검사성적서` 파일의 `QLT03_New(MES전용)` 시트에서 요약·최근 기록 예시를, `통계분석 정리(초지)` 시트에서 통계표를 추출했습니다.
- 통계표에는 원본 시트의 평균, σ, CPK 및 월별 수치를 표시합니다. 원본에서 비어 있는 칸은 대시로 표시하며, 앱에서 재계산한 CPK는 아직 아닙니다.
- `초지345` 시안 데이터는 7,740개 populated rows와 44개 열을 포함합니다. 기본 표는 4,805개 식별 가능한 검사 행을 표시하고, 2,935개의 보조 계산 행도 별도 필터로 조회할 수 있습니다.
- 데이터는 업로드 파일을 기반으로 만든 **시안용 정적 데이터**입니다. 엑셀 재업로드, MariaDB 저장, 서버 측 확인 이력은 구현되지 않았습니다.
- 이상 후보는 같은 호기·품명·검사항목 그룹의 중앙값 및 분포를 이용한 휴리스틱으로 찾으며, 원본 값을 자동 변경하지 않습니다. 현재 파일에서 6건을 후보로 찾았고, 정확한 임계값은 품질팀과 조정이 필요합니다. 확인 완료 상태는 현재 브라우저의 localStorage에만 저장됩니다.
- 요약은 초지 3호기 739건, 초지 4호기 1,643건, 초지 5호기 2,158건이며, 엑셀 판정 불합격은 초지 4호기 2건으로 확인됐습니다.
- 현재 상자그림은 업로드 시점의 원본 정적 데이터입니다. 품목명이 달라지는 경우에는 정확히 승인된 별칭으로만 병합하며, 새 이름은 품질팀 확인이 필요합니다.
- 자동 CPK 계산은 원시 검사 행을 초지기·품목·검사항목·규격·집계기간별로 분리하고, 제공된 Excel 규칙(이동범위, 1.128, 상·하한 규격)을 구현한 뒤 Excel 값과 대조해야 합니다. CPK 자동 계산 기능은 아직 연결되지 않았습니다.

## 개발 실행
```bash
cd /home/user/webapp
npm run build
```

## 배포 및 다음 단계
- 이 화면은 기존 Hono/Cloudflare Pages 미리보기 템플릿에서 실행됩니다.
- Java/Spring Boot와 MariaDB를 실제로 연결하는 운영 시스템은 별도 백엔드 구성 및 사내 서버 배포가 필요합니다. Cloudflare Pages/Workers는 Spring Boot 애플리케이션을 직접 실행하지 않습니다.
- 추천 다음 단계: 업로드 엑셀 데이터 구조 확정 → Spring Boot API 및 MariaDB 스키마 설계 → 엑셀 업로드/중복 방지/갱신 이력 → 실제 데이터 연결 → CPK·추이 분석 구현
